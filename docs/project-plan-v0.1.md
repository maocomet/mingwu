# 项目开发 App · v0.1

## 当前状态

- 当前版本：v0.1 Planning
- 当前阶段：第二关 · 技术架构与数据模型确定
- 平台：Windows
- 使用范围：单用户 / 自用
- 后端：VPS
- AI 接入：OpenAI + Claude Remote MCP
- 状态：规划中

## 使用规则

1. 完成任务后将 `- [ ]` 改成 `- [x]`。
2. 不因为代码已经存在就自动判定任务完成，必须经过实际确认。
3. 一个大关卡的完成条件满足后，才进入下一大关卡。
4. AI 可以更新自己的任务状态，但正式主进度更新最终需要用户确认。
5. 后续如果计划变化，在原文基础上修改，不要重新创建多份互相冲突的计划文件。
